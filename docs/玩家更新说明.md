# 玩家更新说明 · All The Leisures

> 这份说明是给**玩家**看的。你看完只需要记住一件事：
> **每次进游戏之前，先双击一次 `update.bat`。**

---

## 一、第一次准备（只做一次）

1. 从群文件 / 网盘下载 **`All-The-Leisures-update.zip`**。
2. 解压到你的整合包目录里。所谓整合包目录，就是**含 `mods`、`config`、`kubejs` 的那一层**。

   解压后目录大概长这样：

   ```
   你的整合包目录/
   ├─ mods/
   ├─ config/
   ├─ kubejs/
   ├─ scripts/
   └─ update-scripts/          ← 新增的，不要改名
      ├─ packwiz-update.ps1
      ├─ client/update.bat
      └─ server/...
   ```

   > PCL2 / HMCL 用户：右键游戏 → 打开游戏文件夹 / 版本设置，就能看到这个目录。

3. 完成。不需要装 Java 之外的东西，也不需要装任何更新器。

---

## 二、每次更新（30 秒）

1. 双击 `update-scripts\client\update.bat`。
2. 等它跑完。第一次会下载较多文件，以后通常只有几个文件。
3. 看到 `更新完成，可以启动游戏了！` 就关掉窗口，然后用启动器正常启动游戏。

更新器会自动做这些事：

- 只下载**有变化**的文件（不是每次全量重下）；
- 整合包里**已经删掉**的内容，会从你本地一起删掉；
- 你自己**手动改过**的 `config` / `kubejs` / `scripts` 文件会被**还原成官方版本**。
  这是刻意设计的，方便统一联机体验——如果你的改动被还原了，属于正常现象。

---

## 三、网络不好 / 下载失败怎么办

GitHub 在国内经常连不上，脚本会提示失败。这时用代理参数：

1. 在 `update-scripts\client` 文件夹里，**按住 Shift + 右键空白处** → 选择
   `在此处打开 PowerShell 窗口` / `在终端中打开`。
2. 输入下面这行并回车：

   ```bat
   update.bat -Proxy https://ghfast.top
   ```

如果 `ghfast.top` 也不行，可以换一个代理前缀，例如
`https://gh-proxy.com`，写法一样：

```bat
update.bat -Proxy https://gh-proxy.com
```

> 也可以直接编辑 `update.bat`，把 `-Proxy https://ghfast.top`
> 加在文件末尾那一行的 `%*` 前面，以后双击就默认走代理。

其他注意事项：

- 更新过程中不要关窗口，中断了也没关系，重新双击一次会续上。
- 提示 `无法下载` 多半是网络问题，重试或换代理即可；不是整合包坏了。

## 四、常见问题

**Q：双击 `update.bat` 窗口一闪就没了？**
A：说明脚本提前退出了。先在 `update-scripts\client` 里用 Shift+右键打开终端，
再执行 `update.bat`，这样就能看到具体报错。（正常情况下脚本结尾会 `pause`，不会闪退。）

**Q：提示 `Windows PowerShell was not found`？**
A：Win10/11 自带 PowerShell。若确实缺失，请去群里拿一份最新的整合包压缩包手动覆盖。

**Q：更新要花多久？**
A：第一次可能几分钟（取决于网速），之后通常几秒到几十秒。

**Q：我能不更新直接进游戏吗？**
A：可以进，但可能因为配置不一致导致联机出问题。**强烈建议每次先更新。**

**Q：更新会不会删掉我的存档、光影、按键设置？**
A：不会。更新器只管理整合包内的 `config` / `kubejs` / `scripts`，
不碰 `saves`、`shaderpacks`（除非在服务端名单里被专门排除）、`options.txt` 等。

**Q：我改了配置文件，为什么每次更新都被改回去？**
A：同上，这是为了保证和服务端一致。想要个性化设置，请不要改整合包目录里的文件，
或在群里说明需求。

## 五、服务端管理员（Linux / Windows）

服务端使用独立的 `server` 分支，已经剔除纯客户端文件。

**Windows**：把 `update-scripts` 放服务端根目录，开服前双击
`update-scripts\server\update-server.bat`。

**Linux**：

```bash
chmod +x update-scripts/server/update-server.sh
./update-scripts/server/update-server.sh
# 网络不好时：
PROXY=https://ghfast.top ./update-scripts/server/update-server.sh
```

建议接进开服脚本（更新失败就不要开服）：

```bash
./update-scripts/server/update-server.sh || { echo "更新失败，已中止开服"; exit 1; }
java -Xmx8G @user_jvm_args.txt @libraries/net/neoforged/neoforge/21.1.241/unix_args.txt nogui
```
